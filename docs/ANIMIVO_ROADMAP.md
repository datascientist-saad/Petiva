# Animivo roadmap

## Implemented in this release

- Rebrand from Petiva to Animivo
- Species registry (cat, dog, bird + future stubs)
- Bird onboarding fields and grams-based weight
- Separate bird nutrition engine with versioned reference data
- Mammal nutrition engine (existing RER/MER, refactored)
- Nutrition profile persistence service
- Diet plan versioning (mammal + bird)
- Care plan / preventive roadmap page
- Bird habitat & safety checklist
- Wellness insights service (persisted model + generation helpers)
- Subscription-ready entitlements (Free / Plus)
- Veterinary report route (print-ready)
- GCC localization architecture (EN + partial AR)
- Expanded navigation (Today, Nutrition, Health, Care Plan, More)
- Database migration for food catalogue, check-ins, habitat, insights

## Prepared but not activated

- Food product seed catalogue (schema only)
- Stripe/payment provider adapter hook on upgrade page
- Full Arabic translation
- Push/email notification delivery
- Barcode scanning

## Planned future species

- Rabbit, guinea pig, hamster, reptile, fish (registry stubs exist)

## Later milestones

- Vet portal
- GCC product catalogue
- Wearable integration
- Clinic integrations
